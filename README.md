One line, at most 160 characters: a deadpan weather forecast for a city that does not exist.

## Entry

> Tomorrow in Kellwick: highs of 52, lows of 48, and light rain falling upward, which the town council has declined to comment on.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
